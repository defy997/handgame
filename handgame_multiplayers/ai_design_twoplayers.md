# 双人对战ai设计

ai运行结构：
对于当前回合，排除不合法行动（mp不够进行行动），构建一个行动矩阵计算出不同行动组回合结束时自己和对手的状态。
随后采用CFR（Counterfactual Regret Minimization，虚构反悔最小化）搜索n层得到纳什均衡的决策
在添加每一个新的前沿节点的时候都用一个两层的神经网络16→128→64→1，激活函数ReLU，输出函数sigmoid，对于每个局面进行评分输出(0,1)，与其父节点的评分进行差分得到这个节点的静态权重

落地实现（对接现有 Game 接口）：
1. AI 对外接口
   - MinimaxBattleAI：提供 choose_action(hero, enemy) → ActionPlan(action_id, action_name, target_index)
   - PlayerAIConfig / BattleGenome / SearchConfig：用于 Game 注册 AI 配置
2. 状态编码（16维）
   - 每方 8 维：hp, hp_ceiling, mp, mp_ceiling, shield, damage_resistance, revival_armor, alive_flag
   - 归一化后输入网络
3. 搜索与估值
   - 根节点用 CFR 迭代得到混合策略
   - 深度>1 时递归展开，叶子节点走网络估值
   - 终局：胜=+1，负=-1，平=0
4. 训练/推理模型
   - 共享骨干：16→128→64 (ReLU)
   - 价值头：sigmoid 映射到 (0,1)，再线性映射到 (-1,1)
   - 策略头：输出 12 维 logits（覆盖当前版本行动 id 范围）

优化：
搜索顺序上，用所有前沿节点的静态权重作为抽选估值，用一个函数保证中间分数和高分能先被抽到（比如ln(x+1)），或者也可以降低一点高分的权重比如说用上述估分的倒数以一定比例放进$χ^2分布$。
运用LRU Cache（最近最少使用缓存），如果两个不同的决策路径导向了相同的 16 个离散状态组合，直接返回缓存里的均衡分，不用再重复往下搜。
状态哈希表，每个充分展开的状态（亦可称之为节点）都保存其计算得到的估分，如果新搜索到的状态与之相同，则直接利用哈希表的结果。
运用比较剪枝，在对方行动不变的情况下，如果某个行动显然比另一个坏（16个离散状态都单调），那么抛弃这个分支。

神经网络训练：
训练方法：AlphaZero 范式
1. 核心训练机制：AlphaZero 范式对于你的游戏，最适合的架构是 “基于搜索的强化学习”。神经网络不是孤立训练的，而是和你的递归搜索（以及纳什均衡）共生。训练循环：产生数据（自博弈）： 让当前版本的神经网络指导搜索，AI 自己和自己下棋。
   收集经验： 记录下每一个状态 $S$。
   生成标签（Labeling）：胜率标签 $z$： 这一局最终谁赢了（1 或 -1）。
   搜索概率 $\pi$： 根节点的纳什均衡给出的决策的概率分布。
   训练更新： 训练网络，使其输出的分数 $v$ 接近最终结果 $z$，且输出的策略建议 $p$ 接近纳什均衡给出的 $\pi$。
2. 损失函数（Loss Function）的设计为了让网络对“死亡”敏感，Loss 函数必须包含两部分：
   $$Loss = (z - v)^2 - \pi \log(p) + c||\theta||^2$$
   均方误差 $(z - v)^2$： 这一项最关键。当 AI 在 5 血时因为失误输了，由于 $z$ 是 -1，而 $v$ 之前可能预测是 0.5，巨大的误差会强迫网络修改权重，调低低血量时的评分。
   交叉熵 $-\pi \log(p)$： 让网络学会预判纳什均衡，减少实时搜索的压力。
网络结构：16→128→64→1，激活函数ReLU，输出函数sigmoid
冷启动：初始把所有自己的数字均设为1，对手的数字均设为0
递进训练：开始时设定深度n较低，比如为1，随着交叉熵的降低（预测纳什均衡的能力变强），增加n的大小

训练函数与设定接口（见 ai.py）：
1. TrainConfig 主要参数
   - episodes / max_rounds / batch_size / replay_size
   - learning_rate / weight_decay
   - cfr_iters / search_depth
   - plot_interval（更新 Loss 曲线频率）
2. 训练入口
   - train_selfplay(model, config)
   - 训练过程：自博弈 → 记录 (state, pi, z) → 采样更新
3. 实时 Loss 曲线
   - 默认使用 matplotlib 交互模式，训练时实时更新折线
   - 若环境无 matplotlib，自动退化为控制台打印 loss
